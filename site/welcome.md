# libertty

## All terminals are created equal.

Intelligent dictation and agent integrations to make mobile a first-class terminal.

## Install

```sh
curl -fsSL https://install.libertty.sh | bash
```

## Try it here

This page is the app, running a demo in your browser.
Tap the tabs below to visit the terminal, Herdr, and the file browser.
Tap the microphone to dictate a command.
Dictation here runs a small speech model in your browser, so it is slow and less accurate.
The real app transcribes on your computer running libertty, with a larger model that is far faster and more accurate.
